# Agile Project Management and Professional Experience

## Overview

Group coursework for the University of Westminster module 5BUIS021W (2024–2025), focused on applying Agile project management practices to develop a high-fidelity prototype for a web application for Sky.

The proposed application aimed to help Sky employees find and contact engineering teams, explore team information and understand dependencies, replacing reliance on a manually maintained Excel spreadsheet.

## Project Objectives

* Improve access to engineering team information.
* Make it easier to locate and contact relevant teams.
* Visualise engineering team structures and dependencies.
* Reduce issues associated with manual spreadsheet maintenance and outdated information.

## Agile Methods and Activities

* Product positioning statement
* Proto-persona and user needs analysis
* User story mapping and prioritisation
* Minimum Viable Product (MVP) planning
* Iterative development and feedback
* Group collaboration and project planning
* RACI register and group contract

## Prototype

The project involved designing a clickable, high-fidelity web application prototype to demonstrate the proposed user experience, interface layout, navigation and key functionality.

## Professional Considerations

The coursework also considered user feedback, ethical and professional issues, and relevant information systems concerns, including security and legislation.

## Skills Demonstrated

* Agile project management
* Requirements analysis and user story mapping
* Prototype design and user interface planning
* Teamwork and communication
* Task prioritisation and project coordination
* Evaluation of user feedback

## Technologies

Prototyping tools and collaboration software were used as part of the project. The specific tools and technologies are dependent on the deliverables included in this repository.
